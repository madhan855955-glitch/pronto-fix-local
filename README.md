Local Service Finder — Website Development Prompt

Create a modern, responsive Local Service Finder website that helps users find and request nearby Electricians and Plumbers.

1. Website Concept

Build a website where a user can:

Select Electrician or Plumber

Find nearby service providers

View provider profiles

Compare ratings, experience, and estimated charges

Request a service

Track the service request

Give a rating and review after the service is completed

The website should look like a professional real-world service platform, not a basic student project.

2. Home Page

Create an attractive homepage with:

Website logo/name: FixNear

Navigation:

Home

Electricians

Plumbers

My Requests

Login / Sign Up

Hero section:

"Reliable Electricians & Plumbers Near You"

Subtitle:

"Find trusted local professionals and get your home problems fixed quickly."

Add two large service cards:

⚡ Electrician

Wiring

Switch/socket repair

Fan installation

Light installation

Power issues

🔧 Plumber

Pipe leakage

Tap repair

Bathroom plumbing

Water tank problems

Drain blockage

Add a "Find a Professional" button.

3. Location Search

Allow users to enter/select their location.

Example:

📍 Your Location
Enter your area or pincode

Then show nearby electricians and plumbers.

Include filters:

Distance

Rating

Price

Experience

Availability

4. Service Provider Cards

Each electrician/plumber should have a professional card containing:

Profile photo

Name

Service type

⭐ Rating

Number of completed jobs

Years of experience

Distance

Starting price

Availability status

Example:

Arun Electrical Services

⚡ Electrician
⭐ 4.8 (126 reviews)
Experience: 7 years
📍 1.8 km away
Starting from ₹199
🟢 Available now

Buttons:

View Profile
Request Service

5. Provider Profile Page

When the user clicks "View Profile", show:

Profile photo

Name

Service category

Rating

Experience

About the professional

Services offered

Price estimates

Working hours

Completed jobs

Customer reviews

Location

Contact/request button

Include:

"Request This Professional"

6. Service Request System

When the user requests a service, open a form:

Select Problem

Electrical wiring

Fan problem

Light problem

Switch/socket problem

Pipe leakage

Tap problem

Drain blockage

Other

Describe the Problem

Allow the user to type details.

Upload Photo

Allow the user to upload a photo of the problem.

Select Date

Select Preferred Time

Enter Address

Then show:

Estimated Service Charge

Button:

Confirm Service Request

7. Request Tracking

Create a My Requests page.

Display service requests with statuses:

🟡 Request Sent
🔵 Professional Accepted
🟣 Professional On The Way
🟢 Service Started
✅ Completed

Each request should show:

Professional name

Service type

Problem

Date/time

Address

Estimated price

Current status

8. Rating & Review

After a service is completed, allow the customer to:

Give 1–5 stars

Write a review

Upload optional photos

Example:

⭐⭐⭐⭐⭐

"Very quick service and reasonable price."

9. Emergency Service

Add an Emergency Service section.

Example:

🚨 Emergency?

"Need an electrician or plumber immediately?"

Buttons:

Emergency Electrician
Emergency Plumber

Emergency providers should be displayed separately and sorted by distance/availability.

10. Provider Dashboard

Create a separate dashboard for electricians and plumbers.

Provider can:

Create/edit profile

Add services

Set pricing

Set availability

Accept/reject requests

View upcoming jobs

Update job status

View completed jobs

View ratings/reviews

View earnings

11. Admin Dashboard

Create an admin dashboard where the administrator can:

View users

View service providers

Approve/reject providers

View service requests

Manage complaints

Manage reviews

View statistics

Dashboard statistics:

Total Users
Total Electricians
Total Plumbers
Active Requests
Completed Services
Total Revenue

12. Design

Use a modern, clean UI.

Design requirements:

Fully responsive

Mobile-first design

Professional cards

Rounded corners

Smooth hover animations

Clean typography

Simple icons

Clear buttons

Good spacing

Light/dark mode option

Use different visual identity for services:

Electrician → ⚡

Plumber → 🔧

Do not make the website look like a simple template. Make it look like a real startup/service platform.

13. Important Features

Implement:

User registration/login

Provider registration/login

Search

Filters

Location-based provider discovery

Service requests

Request status tracking

Ratings and reviews

Photo uploads

Provider availability

Emergency requests

User dashboard

Provider dashboard

Admin dashboard

14. Future AI Features

Keep the architecture ready for AI features such as:

AI Problem Detection

User uploads a photo of a leaking pipe or electrical problem.

The AI analyzes the image and suggests:

"This appears to be a pipe leakage. A plumber may be required."

Also add:

AI Service Recommendation

User types:

"My bathroom tap is continuously leaking."

The system recommends:

Plumber → Tap Repair

15. Goal

The final website should feel like a real-world platform connecting customers with trusted local electricians and plumbers, with a complete flow:

Find → Compare → Request → Accept → Track → Complete → Review

Build the project with clean, reusable components and organize the code properly so additional services can be added later.
